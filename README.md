# Испанский для ремонта

Курс испанского для русскоязычного мастера по ремонту в Испании. Часть 1: от первого звонка клиента до договора.

## Состав сайта

- `index.html`: главная и меню курса
- `urok1.html`: урок 1, первый звонок (диалоги, числа и время, упражнения)
- `uroki2-6.html`: уроки 2-6 (встреча, объект, материалы, смета, договор)
- `.nojekyll`: отключает обработку Jekyll на GitHub Pages

Сайт статический: только HTML, CSS и JavaScript, без сборки и без серверной части. Единственная внешняя зависимость, шрифт IBM Plex Sans с Google Fonts. Если он не загрузится, страница покажет системный шрифт.

## Публикация на GitHub Pages

1. На github.com нажми New repository, задай имя, например `espanol-reforma`, оставь Public, создай репозиторий.
2. Нажми Add file, затем Upload files, перетащи все файлы из папки сайта, включая `.nojekyll`, и нажми Commit changes.
3. Открой Settings, затем Pages. В разделе Build and deployment выбери Source: Deploy from a branch, Branch: `main`, папка `/ (root)`, нажми Save.
4. Через 1-2 минуты сайт откроется по адресу `https://ТВОЙ-ЛОГИН.github.io/espanol-reforma/`.

Файл `.nojekyll` может не отображаться в проводнике, потому что имя начинается с точки. Если при загрузке его нет, сайт всё равно будет работать.

## Что нужно знать

- Озвучка использует голос браузера или телефона. Если испанского голоса нет, его можно добавить в настройках устройства.
- Прогресс тестов не сохраняется между сеансами.
- Имена и адреса в диалогах вымышленные.
- В уроке 6 про IVA сказано, что тип ставки подтверждает gestor. Это учебная формулировка, а не налоговая консультация.
