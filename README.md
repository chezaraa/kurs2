# Испанский для ремонта

Курс испанского для русскоязычного мастера по ремонту в Испании. Часть 1: от первого звонка клиента до договора. 6 уроков по 15 минут, повторение фраз по дням и аудиоурок для машины.

## Состав сайта

- `index.html`: всё приложение. Экраны «Сегодня», «Курс», «Повторить», «Шпаргалка», уроки из 7 шагов, режим «В машине» и настройки.
- `sw.js`: офлайн-режим. Без интернета курс открывается из памяти телефона.
- `manifest.webmanifest` и папка `icons`: значок курса на главном экране телефона.
- `urok1.html`, `uroki2-6.html`: старые адреса. Они сами переводят на новые экраны, чтобы старые ссылки в группах не сломались.
- `CNAME`: адрес сайта `kurs2.inkcraft.es`. Не удаляй этот файл.
- `.nojekyll`: отключает обработку Jekyll на GitHub Pages.

Сайт статический: HTML, CSS и JavaScript, без сборки на сервере. Шрифты Onest и Unbounded грузятся с Google Fonts. Если они не загрузятся, будет системный шрифт.

## Как обновить сайт на GitHub

1. Открой репозиторий сайта на github.com.
2. Нажми Add file, затем Upload files.
3. Перетащи все файлы и папку `icons` из архива, включая `.nojekyll` и `CNAME`. Файлы с теми же именами заменятся.
4. Нажми Commit changes. Через 1–2 минуты новый сайт откроется по старому адресу.

Если телефон показывает старую версию, закрой вкладку и открой сайт снова.

## Что нужно знать

- Прогресс, колода повторения и имя хранятся в браузере на телефоне. На другом телефоне прогресс начнётся заново.
- Озвучка использует голос телефона. Если испанского голоса нет, его можно добавить в настройках устройства.
- Проверка речи в шаге «Ответь клиенту» работает в Chrome на Android и в Safari на iPhone. Где её нет, ученик сравнивает себя с образцом.
- Имена, адреса и телефоны в диалогах вымышленные.
- Фразы про IVA учебные: ставку для конкретного заказа подтверждает gestor.
